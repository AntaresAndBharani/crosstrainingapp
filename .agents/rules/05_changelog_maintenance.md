# Changelog Maintenance

All notable changes to the app must be documented in `CHANGELOG.md` following the [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) format.

## Agent Instructions:
1. **Always update the changelog:** Before committing your work and opening a PR, ensure you have added an entry summarizing your changes.
2. **Use the `[Unreleased]` section:** Add your notes under the `## [Unreleased]` section at the top of the file. Do not create a new version header yourself; version headers are bumped during release.
3. **Categorize your changes:** Group changes under the appropriate type heading (`### Added`, `### Changed`, `### Fixed`, `### Removed`, `### Security`, `### Deprecated`).
4. **Be descriptive:** Write user-facing, clear descriptions of the new features or fixes rather than purely technical git commit messages.
